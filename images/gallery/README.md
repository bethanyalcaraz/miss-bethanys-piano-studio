# Lesson photos

Photos in this folder appear in the carousel under "Meet Miss Bethany".

- Name them in the order you want them shown: `1.jpg`, `2.jpg`, `3.jpg`, ...
  (`.jpeg`, `.png` and `.webp` work too).
- Don't skip a number — the carousel stops at the first missing one.
- Wide (landscape) photos look best. iPhone HEIC photos need to be saved as
  JPG first.
